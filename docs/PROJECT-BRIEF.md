## 3. Sitemap & Page Structure

- **[ / ] Homepage:**

  - _Stats / Highlight:_ Counter animation untuk angka pencapaian.
  - _Features / Layanan:_ Cards/Grid keunggulan produk/jasa.
  - _Interactive Tabs:_ Showcase fitur/layanan interaktif tanpa reload.
  - _Testimonial Carousel:_ Slider review dari klien.
